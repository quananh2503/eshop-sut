## 2. Câu hỏi khai báo

### 2.1 Công cụ AI đã dùng

- Codex / ChatGPT trong môi trường làm việc local.

### 2.2 Giai đoạn có dùng AI

- [x] Brainstorm / phân tích yêu cầu
- [x] Outline / lập cấu trúc báo cáo
- [x] Viết nháp test case
- [x] Viết nháp Playwright script
- [x] Phản hồi và sửa chữa
- [x] Phân tích kết quả test
- [x] Tổng hợp bug tracker và GitHub Issues
- [x] Soạn báo cáo Markdown/PDF

### 2.3 Prompt / nhiệm vụ chính cho AI

Các prompt chính đã được ghi lại trong:

```text
prompt_log.md
```

Tóm tắt 3 nhóm prompt quan trọng:

1. Phân tích yêu cầu HW02, chính sách AI, chọn chiến lược UI-first Domain Testing.
2. Thiết kế Domain/BVA test cases cho FR-03, FR-07, FR-16, FR-04mb và viết Playwright automation cho FR-03, FR-07, FR-16.
3. Phân tích kết quả test, phân loại bug, chuẩn bị evidence, GitHub Issues, AI Audit Report và báo cáo nộp bài.

### 2.4 Phần cụ thể AI đóng góp

AI hỗ trợ tạo bản nháp ban đầu cho:

- Cấu trúc thư mục HW02.
- Domain/BVA analysis.
- Test cases.
- Playwright scripts cho FR-03, FR-07, FR-16.
- Bug tracker, issue template, issue summary.
- Bản nháp báo cáo chính, AI Audit Report và README nộp bài.

### 2.5 Cách rà soát / chỉnh sửa / xác minh đầu ra AI

Em đã rà soát bằng các cách sau:

- Đọc lại đặc tả `README.md`, `api_specification.md` và yêu cầu HW02.
- Chạy Playwright thật trên UI web/admin local.
- Xem screenshot, error context, trace/video khi test fail.
- Phân biệt lỗi script với bug thật; các candidate không tái hiện được được đánh dấu Rejected.
- Kiểm thử thủ công FR-04mb trên iPhone bằng Expo Go và dùng ảnh chụp màn hình làm evidence.
- Tạo GitHub Issues cho 20 bug đã xác nhận, mỗi issue có evidence render trực tiếp.

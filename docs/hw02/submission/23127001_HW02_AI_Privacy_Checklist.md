# Bảng kiểm Quyền riêng tư và Sử dụng AI có trách nhiệm - HW02

## 1. Trước khi dùng AI

- [x] Đã xác nhận bài HW02 cho phép dùng AI nhưng phải khai báo.
- [x] Đã đọc yêu cầu Assignment Policies và AI Audit Report.
- [x] Hiểu rằng bài làm là cá nhân, không dùng AI để thay thế trách nhiệm kiểm chứng của sinh viên.
- [x] Xác định phạm vi AI chỉ hỗ trợ phân tích, viết nháp, tự động hóa, tổng hợp và kiểm tra; kết luận cuối cùng do sinh viên xác nhận.

## 2. Trong khi dùng AI

- [x] Không nhập dữ liệu cá nhân nhạy cảm ngoài thông tin sinh viên cần khai báo trong bài nộp.
- [x] Không nhập dữ liệu khách hàng/bệnh nhân/tổ chức.
- [x] Không paste code công ty hoặc source code có license hạn chế.
- [x] Chỉ dùng source code EShop SUT được cung cấp cho môn học.
- [x] Ghi lại prompt và output chính trong `prompt_log.md` và AI Audit Report.

## 3. Trước khi nộp bài

- [x] Mọi artifact AI hỗ trợ đã được nêu trong AI Audit Report.
- [x] Có AI Usage Declaration trong báo cáo chính.
- [x] Có Mandatory Disclosure trong báo cáo chính và AI Audit Report.
- [x] Có AI Use Disclosure Form riêng.
- [x] Có prompt log.
- [x] Các test Playwright đã được chạy và có evidence.
- [x] Các bug đã được đưa lên GitHub Issues kèm ảnh evidence.
- [x] Có README nộp bài, self-assessment, test summary và git commit log.

## 4. Cam đoan cuối cùng

Trách nhiệm cuối cùng về độ chính xác, tính nguyên bản và liêm chính của bài nộp thuộc về em. Mọi việc dùng AI đã được khai báo trong báo cáo chính, AI Audit Report và biểu mẫu khai báo AI.
